# Phase 36 — 찬 Area 다리 절단

## 목표

긴 막대기로 두 덩어리를 이은 “꼼수 한 Area”를 막고, 구석에 자연스럽게 모인 형태(짧은 돌출 포함)는 한 Area로 둔다.

## 범위

1. 찬 칸: 일반 4연결 → 관절점 제거 시 양쪽 크기 ≥4이면 그 칸에서 분할(재귀)
2. 직교이웃≥2 자격 필터 제거
3. 빈 Area·cornerRect 패널티 유지

## 비범위

- minPartSize 튜닝 UI
- 빈 칸 다리 절단
