# Phase 32 — 찬 Area 직교 이웃 ≥2만

## 목표

한 칸 돌출도 본체 Area에 넣지 않는다. 대각은 보지 않고, **상하좌우 찬 이웃이 2개 이상**인 칸만 찬 Area로 묶는다.

## 범위

1. 자격: `CountOccupiedCardinals ≥ 2`
2. 자격 칸만 4연결 flood
3. 돌출·끝점 등 비자격 찬 칸은 별도 덩어리
4. 빈 Area·직사각 경로 변경 없음
5. Phase 29의 8이웃 코어·돌출 부착 제거

## 비범위

- 빈 칸 연결 규칙
- 튜닝 수치 재조정

## 수락

- [x] 한 칸 돌출은 본체와 다른 Area
- [x] 대각만으로 이웃 수가 늘지 않음
- [x] 직사각 모서리(직교 2)는 본체에 포함
- [x] 컴파일 오류 없음
