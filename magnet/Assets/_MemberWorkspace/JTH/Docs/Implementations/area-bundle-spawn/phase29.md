# Phase 29 — 찬 칸 두꺼운 Area 연결

## 목표

한 줄짜리 다리로 두 찬 덩어리가 한 Area로 붙는 문제를 막는다. 찬 칸만 두꺼운 연결을 쓰고, 빈 칸은 기존 4연결을 유지한다.

## 범위

1. 찬 코어: 8이웃 찬 ≥3 → 4연결 flood
2. 한 칸 돌출: 4인접 + 8이웃 중 이미 덩어리 ≥2 → 1패스만 부착
3. 남은 가느다란 찬 줄: 별도 4연결 Area
4. 빈 Area·직사각 패널티 경로 변경 없음

## 비범위

- Clean 체이닝 클리어 폴백 (다음 Phase)
- Hospitality 구멍 flood 변경
- 튜닝 수치 재조정
