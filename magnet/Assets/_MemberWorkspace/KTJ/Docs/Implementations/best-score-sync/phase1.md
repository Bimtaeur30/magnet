# Phase 1 — 활성화 시 저장값 복원

## 목표와 승인
- 게임오버 후 갱신 이벤트를 놓치거나 숫자 애니메이션이 중단되어도 UI 재활성화 시 저장된 최고 점수를 표시한다.
- 2026-09-23 사용자 `진행` 승인.

## 구현 범위
- `02_Script/UI/ScoreUI/ScoreUIView.cs`: 최고 점수 초기화를 Awake에서 OnEnable로 옮긴다. 기존 이벤트 구독과 숫자 증가 연출은 유지한다.
- 저장 서비스, 다른 작업자의 코드, 씬과 프리팹은 변경하지 않는다.

## 검증
- Unity 6000.3.10f1 컴파일 성공, 컴파일 오류 없음.
- 임시 메모리 저장소와 ScoreUIView를 이용한 Editor 코드 검증 통과: 최초 저장값, 비활성 중 신기록, 낮은 점수 유지, 중단된 표시 복구, 저장소 재로드.
- 생명주기 메서드를 명시적으로 호출한 검증이며 실제 Play Mode 게임오버 재현과 디스크 저장 검증은 미실시.
